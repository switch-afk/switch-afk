## 🛠️ What i build

Small, sharp Solana command-line tools. Zero runtime dependencies, Node 18+, tests and CI on every repo. Run any of them with one `npx` line.

### Transactions

| Tool | What it does | Run it | npm |
| --- | --- | --- | --- |
| [sol-tx-explain](https://github.com/switch-afk/sol-tx-explain) | Paste a signature, get a plain-English summary | `npx sol-tx-explain <signature>` | ![npm](https://img.shields.io/npm/v/sol-tx-explain) |
| [sol-tx-watch](https://github.com/switch-afk/sol-tx-watch) | Stream a wallet's new transactions live | `npx sol-tx-watch <wallet>` | ![npm](https://img.shields.io/npm/v/sol-tx-watch) |
| [sol-priority-fee](https://github.com/switch-afk/sol-priority-fee) | Current priority fee levels (low / medium / high) | `npx sol-priority-fee` | ![npm](https://img.shields.io/npm/v/sol-priority-fee) |

### Tokens

| Tool | What it does | Run it | npm |
| --- | --- | --- | --- |
| [mint-check](https://github.com/switch-afk/mint-check) | Red-flag checker for a token mint | see repo | |
| [sol-holders](https://github.com/switch-afk/sol-holders) | Largest holders of a mint with % of supply | `npx sol-holders <mint>` | ![npm](https://img.shields.io/npm/v/sol-holders) |

### Wallets

| Tool | What it does | Run it | npm |
| --- | --- | --- | --- |
| [sol-wallet-profile](https://github.com/switch-afk/sol-wallet-profile) | Balance, owner, activity and token holdings | see repo | |
| [sol-rent-reclaim](https://github.com/switch-afk/sol-rent-reclaim) | Find empty token accounts and the SOL you can reclaim | `npx sol-rent-reclaim <wallet>` | ![npm](https://img.shields.io/npm/v/sol-rent-reclaim) |
| [sol-stake-info](https://github.com/switch-afk/sol-stake-info) | Stake account status, lockup, and a wallet's stake accounts | `npx sol-stake-info <stake-account>` | ![npm](https://img.shields.io/npm/v/sol-stake-info) |

### Programs

| Tool | What it does | Run it | npm |
| --- | --- | --- | --- |
| [sol-program-info](https://github.com/switch-afk/sol-program-info) | Upgradeable or not, upgrade authority, last deploy, size | `npx sol-program-info <program>` | ![npm](https://img.shields.io/npm/v/sol-program-info) |
| [sol-idl-peek](https://github.com/switch-afk/sol-idl-peek) | Read a program's on-chain Anchor IDL | `npx sol-idl-peek <program>` | ![npm](https://img.shields.io/npm/v/sol-idl-peek) |
| [sol-pda](https://github.com/switch-afk/sol-pda) | Derive and verify program derived addresses | `npx sol-pda --help` | ![npm](https://img.shields.io/npm/v/sol-pda) |

### Network

| Tool | What it does | Run it | npm |
| --- | --- | --- | --- |
| [sol-rpc-bench](https://github.com/switch-afk/sol-rpc-bench) | Latency, lag, health and side-by-side RPC comparison | see repo | |
| [sol-epoch](https://github.com/switch-afk/sol-epoch) | Epoch progress and time left | `npx sol-epoch` | ![npm](https://img.shields.io/npm/v/sol-epoch) |

> Public RPCs rate-limit. For anything heavy, point a tool at your own endpoint. Each repo's README says which environment variable to set.
